| MID360 雷达 SN | `47MCN7N0033961` | `47MCN8R0037833` |

以上标识共同支持连接对象已变化。两台 machine-id 哈希前缀均为 `8ce56674e080cd57`，SSH 主机密钥也相同，**不能作为唯一身份**。设备树序列号及已查询的芯片 UID 路径未提供可读编号；最终资产绑定仍需核对整机、计算模块铭牌及采购 BOM。

## 3. 遥测、算力口径与待核实项

用户确认机器人已固定 / 吊装并处于调试状态；软件遥测另行记录。**物理固定状态不等于关节已禁用**，下表保留测试前的 mode=1 原始读数。

| 测试前 LowState 只读采样 | 结果 |
| --- | --- |
| 时长 / 有效数据 | **5.0004 秒 / 3,543 条**；约 **708.54 Hz** |
| 数据完整性 | CRC 错误 **0**；非有限数值 **0**；最大接收间隔 **3.675 ms** |
| 模式 | `mode_machine=5`、`mode_pr=0`；**29 个实际关节 mode 均为 1** |
| 错误 / 姿态服务 | 29 轴 error 均为 **0**；姿态服务 **IDLE** |

计算测试后的另一次 5 秒采样为 29 轴 mode=0，详细前后对照见算力报告。本次硬件核验未发布运动命令、未切换机器人模式、未启停机上原有服务。短时错误字段为零，不证明电机运动、机械结构或安全功能合格。

厂家原始 Orin NX 16 GB 规格为：GPU 密集 / 稀疏 INT8 **30 / 60 TOPS**，双 DLA 合计 **20 / 40 TOPS**，模块合计 **50 / 100 TOPS**。这是理论规格，**不是本机持续达到 100 TOPS 的认证**。分别运行的 GPU / DLA 成绩不能相加充当同时吞吐；本机成绩见算力专项报告。规格依据为 [NVIDIA 原始配置 Table 2](https://developer.nvidia.com/blog/?p=95089)，当前记录不作为已启用 Super 的证据。

待核实事项：

- **身份：**整机与模块铭牌 / BOM 尚未核对；临时编号、重复的软件身份不能替代厂家 SN。
- **SSD：**机上缺少 `nvme`、`smartctl`，未安装工具，**未做 SMART 健康检测**；寿命、介质错误及异常断电情况未知。
- **外设与整机：**相机光学质量未验收；雷达脏污警告待闭环；本报告不覆盖全内存、长期热稳定性、整机功耗及运动安全。
